# Shot 압력계와 추출 그래프

## 아두이노

`shot/shot.ino`를 Arduino IDE에서 열고 보드에 업로드합니다.
`LiquidCrystal_I2C` 라이브러리가 필요합니다. 기존 구성은 A0 압력 입력,
I2C LCD 주소 `0x27` / 16×2, 5V / 10비트 ADC 기준입니다.
압력 보정값은 기존 코드를 유지합니다. LCD와 시리얼 출력은 초당 약 5회,
시리얼 속도는 **115200 baud**, 형식은 한 줄에 압력 숫자 하나입니다.
소수점 둘째 자리 표시는 센서나 ADC의 측정 정확도를 높이지 않습니다.

## 컴퓨터에서 추출 그래프 보기

USB 보드가 연결된 **본인 컴퓨터**에서 실행합니다. Python 3와 PC용 Chrome 또는
Edge가 필요합니다. 추가 Python/JavaScript 패키지는 필요하지 않습니다.

### 간편 실행 (Windows)

저장소 전체를 다운로드하고 **압축을 푼 뒤 `Open_Graph.bat`를 더블클릭**하세요.
Python 3.8 이상이 설치되어 있으면 프로그램 위치를 자동으로 찾아 서버를 실행하고,
Chrome으로 그래프를 엽니다. Chrome을 찾지 못하면 Edge 또는 기본 브라우저를 사용합니다.
첫 실행에서만 **아두이노 연결**을 눌러 USB 포트를 허용하세요.
이후 같은 Chrome 프로필에서는 이전에 허용한 장치를 찾아 자동 연결합니다.
주소는 권한 유지를 위해 `http://127.0.0.1:10001/`로 고정됩니다.
이미 프로그램이 실행 중이어서 포트가 사용 중이면 기존 실행창을 종료하고 다시 실행하세요.
Chrome 권한을 삭제하거나 다른 PC/프로필을 사용하면 다시 한 번 포트를 허용해야 합니다.
허용된 장치가 여러 개이고 사용할 보드를 구분할 수 없으면 수동 선택을 안내합니다.
프로그램을 연 뒤 USB를 연결하는 경우에도 허용된 장치의 연결 이벤트에서 자동 연결을 시도합니다.
시리얼 모니터나 다른 그래프 탭이 포트를 사용 중이면 해당 프로그램에서 연결을 해제하세요.
바탕화면에 이 파일의 바로가기를 만들어도 됩니다.

종료할 때는 필요하면 먼저 그래프 이미지를 저장한 뒤 **그래프 탭 또는 Chrome 창을 닫으세요.**
마지막 그래프 탭을 닫으면 약 3초 후 서버와 실행창이 함께 종료됩니다.
새로고침에는 종료 유예 시간을 두며, 다른 그래프 탭이 열려 있으면 실행을 유지합니다.
백그라운드 탭의 시간 제한으로 종료하지 않습니다. 실행창의 Enter, Ctrl+C 또는 X 버튼으로도 종료할 수 있습니다.
Chrome 강제 종료나 비정상 종료에서는 닫기 알림이 전달되지 않을 수 있으므로 실행창에서 직접 종료하세요.
다시 열 때도 같은 파일을 더블클릭하면 됩니다. 저장하지 않은 기록과 메모는 닫으면 사라집니다.
Python이 없다는 메시지가 나오면 Python을 설치한 후 다시 실행하세요.

macOS/Linux에서는 저장소 폴더에서 `python3 open_graph.py`를 실행할 수 있습니다.
자동으로 열린 브라우저가 Firefox/Safari라면 실행창의 주소를 Chrome/Edge에 입력하세요.

### 직접 실행

1. 이 저장소를 다운로드하거나 `git pull`로 최신 파일을 받습니다.
2. Arduino IDE의 시리얼 모니터와 플로터를 닫습니다. 같은 포트를 동시에 사용할 수 없습니다.
3. 저장소 폴더에서 다음 명령을 실행합니다.

   ```sh
   python open_graph.py
   ```

   Windows에서 `python`이 없다면 `py`를, macOS/Linux에서는 `python3`를 사용할 수 있습니다.

4. 자동으로 열린 브라우저를 사용하거나 실행창에 표시된 주소를 Chrome에 입력합니다.
5. 이전에 허용한 보드는 자동 연결됩니다. 처음이거나 자동 연결되지 않으면
   **아두이노 연결**을 누르고 USB 시리얼 포트를 선택합니다.
   보드가 재시작되면 압력 데이터가 도착할 때까지 잠시 기다립니다.

- Y축: 추출 압력 0~20bar 고정(5bar 눈금), X축: 추출 시작부터 경과 시간(초).
  X축은 처음 0~60초이며, 60초를 넘으면 자동으로 확장됩니다.
  20bar를 넘는 값은 그래프 영역 밖에 표시하지 않으며 현재 압력 숫자로 확인할 수 있습니다.
- 그래프 위에 피크 압력과 추출 시간이 표시되며, 완료 후 최종 시간이 고정됩니다.
  피크 압력 높이에 노란 가로 점선이 표시되고 저장 이미지에도 포함됩니다.
  그래프 테두리는 추출 전 회색, 추출 중 노란색, 추출 완료 민트색입니다.
  Y축 범위를 넘는 20bar 초과 피크는 숫자로 확인하며 점선은 표시하지 않습니다.
- **추출 메모** 창에 도징량, 물온도, 속도, 원두, 맛 등을 자유롭게 입력할 수 있습니다(최대 1,000자).
  메모 입력 중 스페이스바는 띄어쓰기로 동작합니다. 기록을 완료하려면 완료 버튼을 누르거나
  메모창 밖을 클릭한 뒤 스페이스바를 누르세요. 메모는 다음 추출에서도 유지되어 수정할 수 있습니다.
- 추출 완료 후 **이미지 저장**을 누르면 그래프·피크 압력·최종 시간·메모가 한 PNG로 저장됩니다.
  저장 위치는 `Open_Graph.bat`와 같은 폴더 아래의 **data** 폴더입니다.
  이름은 PC 현지 시간의 추출 시작 날짜와 날짜별 저장 순번입니다(예: `2026-10-16_001.png`).
  저장할 때마다 기존 파일 다음 번호를 사용하며 재실행해도 기존 파일을 덮어쓰지 않습니다.
  자정 이후 저장해도 추출 시작 날짜가 사용됩니다. 저장 결과는 화면에 표시됩니다.
  이미지 파일은 Git에 자동 업로드되지 않습니다.
  폴더 저장에는 최신 실행 프로그램이 필요하며, `python -m http.server`로는 저장할 수 없습니다.
- 오른쪽 **추출 히스토리**에서 `data` 폴더의 기존 기록을 날짜와 추출 번호의 최신순으로 볼 수 있습니다.
  새 이미지를 저장하면 목록이 자동 갱신됩니다. 파일을 직접 추가했다면 **새로고침**을 누르세요.
  기록을 선택하면 그래프와 메모를 크게 확인하고 이미지를 다시 다운로드할 수 있습니다.
  **닫기** 또는 Esc로 돌아옵니다. 히스토리를 보는 동안에도 진행 중인 추출은 계속 기록됩니다.
  프로그램을 다시 실행해도 같은 `data` 폴더의 기록을 읽습니다. 좁은 화면에서는 히스토리가 아래에 표시됩니다.
- 압력이 **1bar를 초과**하면 자동 시작합니다. 연결 당시 이미 초과해도 시작합니다.
- 그래프 화면에서 **스페이스바** 또는 **추출 시작** 버튼으로 수동 시작할 수 있습니다.
- 추출 중 **스페이스바** 또는 **추출 완료** 버튼을 누르면 기록과 시간이 멈춥니다.
- 추출 중 압력이 **초당 2bar 이상 속도로 하강**하면 자동 완료됩니다.
  예를 들어 0.2초 사이 9→8.6bar로 떨어지면 완료됩니다. 마지막 하강 측정점도 그래프에 남습니다.
  실제 수신 간격으로 계산하며, 몰려 들어온 데이터의 0.1초 미만 간격과 1초를 넘는 수신 공백은
  급락 판정에서 제외합니다. 화면에는 **추출 완료 (자동)**가 표시됩니다.
- 완료 후 압력이 1bar 이하로 내려갔다가 다시 초과하면 다음 추출을 시작합니다.
  수동으로는 바로 다음 추출을 시작할 수 있습니다.
- 다음 추출이 시작되면 이전 그래프가 초기화됩니다. 필요하면 먼저 **이미지 저장**을 누르세요.
- 연결을 끊으면 진행 중인 기록이 종료되고 그래프는 남습니다.
- 시간은 PC의 시리얼 수신 시간을 기준으로 합니다. 현재 그래프 측정점은 약 초당 5개입니다.

이 웹 화면은 로컬에서만 동작하며 외부 서버로 측정값을 전송하지 않습니다.
클라우드 작업 환경에서는 본인 PC의 USB에 직접 접근할 수 없습니다.
연결 오류가 나면 포트를 사용하는 다른 프로그램을 닫고, USB 케이블과 보드 드라이버,
운영체제의 시리얼 포트 권한을 확인하세요. Firefox와 Safari는 이 화면의 Web Serial을
지원하지 않습니다.

## 개발 검증

```sh
node --test graph/*.test.mjs
python -m unittest discover -s tests -v
```

실제 보드 연결·압력값 검증은 USB가 연결된 컴퓨터에서 수행해야 합니다.

## LCD는 동작하지만 PC 압력이 멈출 때

2초 이상 새 압력을 받지 못하면 현재 압력에 `—`를 표시하고 마지막 수신 후 경과 시간을 안내합니다.
일시적인 시리얼 읽기 오류는 포트를 다시 열지 않고 최대 3회 수신을 재시도합니다.
USB 분리나 PC 절전으로 연결 자체가 끊긴 경우에는 수동으로 다시 연결해야 합니다.
진행 중이라면 추출 완료를 누르고 기록을 저장한 뒤, 연결 해제 → 아두이노 연결을 시도하세요.
반복되면 화면의 오류 문구, USB 케이블/허브, PC 절전 진입 여부를 확인하세요.
수신하지 못한 구간의 측정값은 복원되지 않습니다.
